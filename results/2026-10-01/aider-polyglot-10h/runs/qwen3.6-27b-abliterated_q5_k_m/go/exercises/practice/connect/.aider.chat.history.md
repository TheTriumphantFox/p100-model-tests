2.  **Connectivity Check**:
    *   Player 'O' wins if there is a path of 'O's from the top row to the bottom row.
    *   Player 'X' wins if there is a path of 'X's from the leftmost column to the rightmost column.

3.  **Hex Grid Neighbors**: In a hex grid represented in this staggered text format, a cell at `(r, c)` has 6 neighbors. The exact offsets depend on the row parity or the specific layout. Looking at the example:
    ```
    . O . X .
     . X X O .
      O O O X .
       . X O X O
        X O O O X
    ```
    This is a standard axial/cube coordinate representation flattened into rows.
    Let's define the neighbors for a cell `(r, c)` in this grid layout.
    The grid is effectively:
    Row 0: cols 0..N
    Row 1: cols 0..N (shifted visually, but logically aligned in our parsed grid)
    
    Actually, a simpler way to handle the hex connectivity in this specific text representation is to realize that the spaces are just padding. If we strip spaces, each row is a sequence of cells.
    Let's parse the board into a `[][]byte` or `[][]string` where `board[r][c]` is the character at row `r`, column `c`.
    
    The neighbors of `(r, c)` in a hex grid laid out like this are:

    - `(r-1, c)` and `(r-1, c+1)` (Top-Left/Top-Right? Or Top/Top-Right?)

    Let's verify with the visual structure.

    - Same row: left, right
    - Row above: left-ish, right-ish
    - Row below: left-ish, right-ish
    
    Standard offsets for this "staggered" grid representation (where each row is shifted by 1 space in text, but we strip spaces so indices align logically):
    If we treat the grid as a regular 2D array after stripping spaces:
    Neighbors of `(r, c)`:
    1. `(r, c-1)`
    2. `(r, c+1)`
    3. `(r-1, c)`
    4. `(r-1, c+1)`
    5. `(r+1, c-1)`
    6. `(r+1, c)`
    
    Let's double check this connectivity.
    In a hex grid, if you move "up", you can go to the cell directly above or the one to the right of the one above (depending on orientation).
    Given the visual:
    ```
      0 1 2
     0 1 2
    ```
    Cell `(1, 0)` is below and between `(0, 0)` and `(0, 1)`. So `(1, 0)` connects to `(0, 0)` and `(0, 1)`.
    This matches offsets: `(r-1, c)` and `(r-1, c+1)` for the row above.

    - Up-Left: `(r-1, c)`
    - Up-Right: `(r-1, c+1)`
    - Left: `(r, c-1)`
    - Right: `(r, c+1)`
    - Down-Left: `(r+1, c-1)`
    - Down-Right: `(r+1, c)`
    
    This seems consistent.

	"errors"

func ResultOf(lines []string) (string, error) {
	// Parse the board
	board := make([][]byte, len(lines))
	for r, line := range lines {
		row := make([]byte, 0)
		for _, ch := range line {
			if ch != ' ' {
				row = append(row, byte(ch))
			}
		}
		board[r] = row
	}

	// Check for O winning (Top to Bottom)
	if hasPath(board, 'O', func(r, c int) bool { return r == 0 }, func(r, c int) bool { return r == len(board)-1 }) {
		return "O", nil
	}

	// Check for X winning (Left to Right)
	if hasPath(board, 'X', func(r, c int) bool { return c == 0 }, func(r, c int) bool { return c == len(board[r])-1 }) {
		return "X", nil
	}

	return "", nil
}

func hasPath(board [][]byte, player byte, isStart, isEnd func(r, c int) bool) bool {
	if len(board) == 0 {
		return false
	}

	visited := make([][]bool, len(board))
	for r := range visited {
		visited[r] = make([]bool, len(board[r]))
	}

	queue := [][2]int{}

	// Initialize queue with all starting cells
	for r := 0; r < len(board); r++ {
		for c := 0; c < len(board[r]); c++ {
			if board[r][c] == player && isStart(r, c) {
				queue = append(queue, [2]int{r, c})
				visited[r][c] = true
			}
		}
	}

	// Directions for hex grid neighbors
	// (dr, dc)
	dirs := [][2]int{
		{0, -1},  // Left
		{0, 1},   // Right
		{-1, 0},  // Up-Left
		{-1, 1},  // Up-Right
		{1, -1},  // Down-Left
		{1, 0},   // Down-Right
	}

	for len(queue) > 0 {
		curr := queue[0]
		queue = queue[1:]
		r, c := curr[0], curr[1]

		if isEnd(r, c) {
			return true
		}

		for _, d := range dirs {
			nr, nc := r+d[0], c+d[1]
			if nr >= 0 && nr < len(board) && nc >= 0 && nc < len(board[nr]) {
				if !visited[nr][nc] && board[nr][nc] == player {
					visited[nr][nc] = true
					queue = append(queue, [2]int{nr, nc})
				}
			}
		}
	}

	return false
}
