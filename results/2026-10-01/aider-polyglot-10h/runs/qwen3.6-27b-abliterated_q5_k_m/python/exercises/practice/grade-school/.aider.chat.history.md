I've implemented the `School` class with the following features:
- `__init__`: Initializes an empty dictionary for the roster and a set to track added students.
- `add_student`: Adds a student to a grade if they haven't been added before. Returns `True` if added, `False` otherwise.
- `roster`: Returns a sorted list of all students in all grades.
- `grade`: Returns a sorted list of students in a specific grade.
- `added`: Returns a list of students that have been successfully added to the roster.

grade_school.py
```
class School:
    def __init__(self):
        self._roster = {}
        self._added_students = set()

    def add_student(self, name, grade):
        if name in self._added_students:
            return False
        
        if grade not in self._roster:
            self._roster[grade] = []
        
        self._roster[grade].append(name)
        self._added_students.add(name)
        return True

    def roster(self):
        result = []
        for grade in sorted(self._roster.keys()):
            result.extend(sorted(self._roster[grade]))
        return result

    def grade(self, grade_number):
        if grade_number in self._roster:
            return sorted(self._roster[grade_number])
        return []

    def added(self):
        return list(self._added_students)
```
