To implement the `combinations` function for the Killer Sudoku Helper, I will replace the placeholder implementation in `killer-sudoku-helper.js`.

The function needs to:
1.  Accept `cage` object with `sum`, `size`, and `exclude` properties.
2.  Find all unique combinations of `size` distinct digits (1-9) that sum up to `sum`.
3.  Exclude any combinations containing digits present in the `exclude` array.
4.  Return the valid combinations sorted (both the combinations themselves and the list of combinations).

I will use a backtracking approach to generate combinations efficiently, ensuring digits are strictly increasing to avoid duplicates and respect the "distinct digits" rule.

killer-sudoku-helper.js
```javascript
//
// This is only a SKELETON file for the 'Killer Sudoku Helper' exercise. It's been provided as a
// convenience to get you started writing code faster.
//

export const combinations = (cage) => {
  const { sum, size, exclude = [] } = cage;
  const results = [];

  const backtrack = (start, currentSum, currentCombo) => {
    if (currentCombo.length === size) {
      if (currentSum === sum) {
        results.push([...currentCombo]);
      }
      return;
    }

    for (let i = start; i <= 9; i++) {
      if (exclude.includes(i)) {
        continue;
      }
      if (currentSum + i > sum) {
        break;
      }
      currentCombo.push(i);
      backtrack(i + 1, currentSum + i, currentCombo);
      currentCombo.pop();
    }
  };

  backtrack(1, 0, []);
  return results;
};
```
