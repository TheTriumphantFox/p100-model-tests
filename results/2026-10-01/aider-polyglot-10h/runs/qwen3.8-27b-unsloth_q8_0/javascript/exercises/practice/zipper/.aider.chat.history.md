#### [Zippers][zipper] are a purely functional way of navigating within a data structure and manipulating it.

The `Zipper` class will maintain:
1.  `focus`: The current node being focused on.
2.  `path`: An array of directions taken to get to the current focus from the root. Each element is either `'left'` or `'right'`.

This approach allows us to:
-   `toTree()`: Reconstruct the tree by starting from the root (derived from the path and focus) and applying the path steps. Actually, a simpler way for `toTree` is to keep the whole tree structure implicitly or explicitly. However, the standard zipper pattern usually stores the "context" (the rest of the tree) rather than just the path.
    
    Let's refine the design. A more robust zipper for a binary tree typically stores:
    -   `focus`: The current node.
    -   `left`: The left sibling subtree (if we came from the right) or null.
    -   `right`: The right sibling subtree (if we came from the left) or null.
    -   `parent`: The parent zipper (or null if at root).
    
    Alternatively, and often simpler in JS without complex object graphs, we can store:
    -   `focus`: The current node object.
    -   `path`: An array of objects describing the path back to the root. Each step contains the direction taken and the sibling node that was left behind.
    
    Let's use the `path` approach as it's easier to implement immutably (returning new zippers).
    
    Structure of `path` elements:
    -   `{ dir: 'left', sibling: rightNode }` means we moved left, so the right node is the sibling.
    -   `{ dir: 'right', sibling: leftNode }` means we moved right, so the left node is the sibling.
    
    Wait, if we move left from a parent, the parent's right child is the sibling.
    If we move right from a parent, the parent's left child is the sibling.
    
    So:
    -   `left()`: New focus is `this.focus.left`. New path is `this.path.concat([{ dir: 'left', sibling: this.focus.right }])`.
    -   `right()`: New focus is `this.focus.right`. New path is `this.path.concat([{ dir: 'right', sibling: this.focus.left }])`.
    -   `up()`: Pop the last element from path. Let it be `{ dir, sibling }`. The new focus is a new node with:
        -   `value`: same as parent's value (we need to store parent's value? No, we lost it).
        
    Ah, the problem with just storing `focus` and `path` with siblings is that we lose the `value` of the ancestors.
    
    So, each step in the path must also store the `value` of the ancestor node.
    
    Revised `path` element:
    -   `{ dir: 'left', value: parentValue, sibling: rightNode }`
    -   `{ dir: 'right', value: parentValue, sibling: leftNode }`
    
    Then `up()`:
    -   Pop last step.
    -   New focus is `{ value: step.value, left: (step.dir === 'left' ? this.focus : step.sibling), right: (step.dir === 'right' ? this.focus : step.sibling) }`.
    -   New path is the remaining path.
    
    `toTree()`:
    -   Start with `current = this.focus`.
    -   Iterate `this.path` in reverse.
    -   For each step, create a new node with `step.value`, and attach `current` and `step.sibling` appropriately based on `step.dir`.
    -   Return the final root.
    
    `setValue(val)`:
    -   Return new Zipper with `focus` replaced by `{ ...this.focus, value: val }` and same path.
    
    `setLeft(tree)`:
    -   Return new Zipper with `focus` replaced by `{ ...this.focus, left: tree }` and same path.
    
    `setRight(tree)`:
    -   Return new Zipper with `focus` replaced by `{ ...this.focus, right: tree }` and same path.

    `fromTree(tree)`:
    -   Return new Zipper with `focus: tree` and `path: []`.

    `value()`:
    -   Return `this.focus.value`.

// This is only a SKELETON file for the 'Zipper' exercise. It's been provided as a

export class Zipper {
  constructor(focus, path) {
    this.focus = focus;
    this.path = path;
  }

  static fromTree(tree) {
    return new Zipper(tree, []);
  }

  toTree() {
    let current = this.focus;
    for (let i = this.path.length - 1; i >= 0; i--) {
      const step = this.path[i];
      if (step.dir === 'left') {
        current = {
          value: step.value,
          left: current,
          right: step.sibling,
        };
      } else {
        current = {
          value: step.value,
          left: step.sibling,
          right: current,
        };
      }
    }
    return current;
  }

  value() {
    return this.focus.value;
  }

  left() {
    if (!this.focus.left) {
      return null;
    }
    return new Zipper(this.focus.left, [
      ...this.path,
      { dir: 'left', value: this.focus.value, sibling: this.focus.right },
    ]);
  }

  right() {
    if (!this.focus.right) {
      return null;
    }
    return new Zipper(this.focus.right, [
      ...this.path,
      { dir: 'right', value: this.focus.value, sibling: this.focus.left },
    ]);
  }

  up() {
    if (this.path.length === 0) {
      return null;
    }
    const lastStep = this.path[this.path.length - 1];
    const newPath = this.path.slice(0, -1);
    let newFocus;
    if (lastStep.dir === 'left') {
      newFocus = {
        value: lastStep.value,
        left: this.focus,
        right: lastStep.sibling,
      };
    } else {
      newFocus = {
        value: lastStep.value,
        left: lastStep.sibling,
        right: this.focus,
      };
    }
    return new Zipper(newFocus, newPath);
  }

  setValue(value) {
    return new Zipper(
      { ...this.focus, value: value },
      this.path
    );
  }

  setLeft(left) {
    return new Zipper(
      { ...this.focus, left: left },
      this.path
    );
  }

  setRight(right) {
    return new Zipper(
      { ...this.focus, right: right },
      this.path
    );
  }
}
